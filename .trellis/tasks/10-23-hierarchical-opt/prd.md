## 3. 臂 A：Worker 精简（第 1 次重训，不等诊断，可先跑）

**假设**：Worker 的 $\alpha$ 块与排空头是死重，移除后 7/7 门仍成立。

> **口径更正（2026-10-23）**：初稿误写 $4K\to3K$。经 `rsma_env.py:232` 核实，连续动作 =
> [$\alpha$(K), $p$(K), $d$(K)] = 3K=72，解码序另计 K=24，Worker 总动作 4K=96。砍 $\alpha$ 与 $d$
> 两块后剩 $p$(K)+解码序(K) = **2K=48**，动作空间**减半**。

**改动**：
- 新增**精简模式**代码路径：动作 $4K=96\to2K=48$（删 Worker $\alpha$ 块、删排空头 $d_k\equiv1$；连续部分 $3K\to K$，解码序保留）；
- 旧路径**只读保留**（供加载旧 checkpoint 与回滚），不删代码；
- Meta 与解码序**不动**。

**判定门（全部满足才算成功）**：
1. 官方 7×50 **7/7 逐点门**（`points_met=7`）；
2. 字典序 score 不劣于冠军的第一分量（`points_met`），性能数值只作记录；
3. **结构指标**（见 §6）：动作空间维度下降 $\ge 40\%$（**主产出**），且参数量、单时隙时延**不升高**（约束，允许持平）。

> **改门记录（2026-10-23，用户裁决选 b）**：本条原写「结构指标三项均有下降」，
> 属 §6「三口径都**报**」被误写成「都**判**」。实测参数量仅降 0.08\%、时延持平

> 误判为失败。现改为「动作维度降 ≥40\% 为主产出 + 参数量/时延不升为约束」，
> 与 Q15 定的结构判据（动作空间 $4K	o2K$）一致。

**产出**：无论成败都可写——成功 = "可解释性驱动的架构精简：4 个动作头只需 1 个"；失败 = "死重不等于可删，分层动作域有隐性耦合"。

## 4. 臂 B：Meta 激励修复 + 分组进奖励（第 2 次重训）

**假设**：分组失效的根因是 (i) 激励量纲小 3 个数量级且 `balance` 在坍缩侧最优，(ii) `group_ids` 不进奖励。两者同时修才有效。

**改动**：
1. **修 `balance` bug**：改为对全部 $G$ 组统计（空组计入），消除"恒单组拿满分"；
2. **提激励量纲**：多样性项不参与 `meta_reward_scale=0.02` 的整体缩放（或改成门槛式：$n_{\rm unique}<G$ 时扣分）；
3. **建分组的奖励通道**：把 `group_ids` 接进 Lyapunov——组级 DVQ $Y_g$、组级交付核算与欠账惩罚，使分组**改变奖励**而不只是改变速率与 $\alpha$ 展开；
4. `meta_freeze_episodes` 恢复默认 0（本 run 被覆盖为 2000，属非默认配置）。

**判定门**：
1. 官方 7×50 **7/7 门**；
2. **确定性执行下的组数**：每时隙 $n_{\rm unique}$ 均值 ≥ 2（现状 1.22）；
3. 组级 $\alpha$ 的跨状态标准差 $\ge 0.05$（现状 0.087 跨 SNR，但确定性下单状态 $\sigma=0.028$）；
4. 结构指标不劣化（参数量可略增，允许）。

**失败判据**：7/7 门掉了 → 回退到**只修激励**（改动 1+2，不含 3）作第 3 次重训，定位是"奖励通道改动过大"还是"激励不足"。

**产出**：成功 = "分层约束承载：慢层分组 + 组级虚拟队列"；失败 = "该任务不需要用户分组，单组即最优"（负结果，诚实写）。

## 5. 臂 C：目标条件化（第 3 次重训，依赖 B）

> **改臂记录（2026-10-25，用户裁决选 a）**：本臂原设计为「Meta 下发**每组**交付目标
> $\zeta_g$，Worker 观测加入 $(g_k, \zeta_{g_k})$」。臂 B 的结果改变了前提——分组机制修复后
> 分组多样性 1.22→1.91、$lpha$ std 0.028→0.145，机制确已生效，但交付率降
> $0.019pprox4\sigma_{m seed}$。**以分组为载体继续走是负期望。**
>
> 现改为「**去分组、留分层**」：$G=1$（放弃用户分组），Meta 只输出**单一慢尺度目标
> $\zeta$ 与 $lpha$**，Worker 按 $(\zeta, lpha)$ 条件执行；$Y$ 虚拟队列回到聚合口径。
> 分层结构完整保留，避开分组的负效应，同时 Meta 的分组头可一并去除。
> **这是本轮第二次也是最后一次改臂，之后不得再改。**

**假设**："慢层下发目标、快层达成"比"慢层拆个 $\alpha$"更接近分层强化学习的本义。

**改动**：
- Meta 每 $T_s$ 输出每组交付目标 $\zeta_g$（可叠组级 DVQ $Y_g$）；
- Worker 观测加入 $(g_k,\ \zeta_{g_k})$；
- 奖励按组核算达成度（与 B 的组级通道复用）。

**判定门**：7/7 门 + 结构/机制指标（每组 $\zeta_g$ 有跨状态方差，Worker 的功率分配随 $\zeta_g$ 变化）。

**失败判据**：7/7 门掉了 → 判失败，记为"目标条件化在本架构下不稳定"，不再重试。

## 7. 评估口径：确定性 vs 采样（必须写进论文）

诊断显示两条路径结论不同：
- **确定性（argmax）**：$n_{\rm unique}$ 均值 1.22，$\alpha\approx0.135$ —— 这是**部署/官方评估**用的路径；
- **采样**：$n_{\rm unique}=4$ 全覆盖，$\alpha$ mean 0.466 —— 这是**训练时 PPO 优化**的路径。

**规则**：所有分组/ $\alpha$ 的统计**必须标注是哪条路径**；官方评估与交付物一律用确定性路径；臂 B 的判定门 2、3 用确定性路径测。

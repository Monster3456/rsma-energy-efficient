## 1. 问题（三句话）

1. 单策略须同时满足 7 个 SNR 点的逐点双门，约束不可按点分解（M0 已形式化，`eq:p2_point`）。
2. 奖励塑形有概率性天花板（命题 T，措辞已收紧）；提升只允许改动作空间可行域几何 Π 或数据 D_init。
3. 形状探针显示：可行方向是**份额集中度**（0 dB 下功率↑→交付↓，集中度↑→交付↑），且 logit
   输出域有上限——故 M3 在**输出域内**加一个"交付门投影"，由构造保证
   $\mathrm{range}(\phi_\theta)\subseteq\mathcal{F}$。

## 2. 设计 $\phi_\theta$（待 §7 的两处细化确认后定型）

### 2.1 分层动作

沿用 2K 精简动作（armA 已证 96→48 无损）：`a = [p_logits(K), order(K)]`。
元层保留（分层是骨架）：Meta 输出组级 α + ζ（armC 通道已接线）。

### 2.2 核心新增：集中度投影头（Worker 输出后处理，结构与职责的固定部分）

```
p_logits_raw = WorkerHead(s, z)                    # 既有自注意力主干，不变
l_mean = mean(p_logits_raw)
tau* = RootFind( tau  ↦  zeta_hat(s, l_mean + tau·(l_raw - l_mean)) >= zeta_gate(s) + margin_cert )
p_logits = clip(l_mean + tau*·(l_raw - l_mean), -ACT_BOUND, ACT_BOUND)
```

- `zeta_hat` 采用 **fast surrogate**（`diff_engine` 的可分快版或单步教师近似），τ* 用
  **少迭代求根**（bisection 5-7 步 或 3 步拟牛顿，均为可微）；幅度限制在 `tau ∈ [0, tau_max]`
  （方向先验：只允许朝集中方向，不允许均匀化）。
- **设计要点（与 banlist 划界）**：这是**动作空间输出域的几何约束**（改变 Π），
  不是奖励塑形（不动 $J$）、不是动作后纠错的 Safety Layer（该概念已被约束栈判定无效，
  区别：本投影由**固定结构与引擎一致性**导出，非可学习的纠错网络）、不是梯度投影
  （改输出域不改梯度方向）。
- **微分**：τ* 的梯度经 Implicit/直通（straight-through）回传给 Worker 主干，使策略在
  投影存在下仍可学习。

### 2.3 证书（certification，训练与验证分离）

- 训练期：clean checkpoint 每 T_cert 作一次 $S_{\rm cert}$ 抽样，检验
  $\hat\zeta_s\ge\zeta_{\rm SDMA}(s)$ 的**实证违约率**；
- 训练后：正式评估前在更大 $S_{\rm cert}$ 出具违约率 + 每点余量分布；
- **E1 门以官方 7×50 为准；cert 只作工程护栏**（二者口径不同，勿混）。

### 2.4 与 armC ζ 通道的关系

ζ 继续作 **验证/目标坐标**（obs 已有）；τ 是**结构坐标**（不进 obs，只进头）。两者解耦。

## 3. 训练协议

| 阶段 | 内容 | 训练量 |

- **回滚**：现有 checkpoint 一律不动；M3 全部进新 exp 目录（`logs/m3_*/`）。

## 6. 风险与退路

| 风险 | 概率 | 退路 |
|---|---|---|
| τ* 求根在 fast surrogate 上不稳/振荡 | 中 | 退 3 步拟牛顿 + 幅度 clip；surrogate 换完整 engine（训练慢但稳） |
| 投影后策略塌缩（多样性丢失，E1 反降） | 中 | δ-松弛：仅在预测违约时投影（失败侧投影），成功侧原样——保持已学行为 |
| E2 差在 0.0017 分辨率测不出 | 中 | 连续"收复比例" + 配对检验升级 |
| 审稿质疑"近似 Safety Layer" | 低 | 文档已划界：固定结构 + 引擎一致性 + Π 改变 + 无纠错网；引命题 T 推论 |

## 7. 设计待定（预注册，改这里必须留痕）

1. **[待定-1] τ* 求根算法**：bisection(5-7 步) vs 3 步拟牛顿 vs 摊销 τ-head（直通）。M4 裁决。
2. **[待定-2] fast surrogate**：diff_engine 截断版 vs 完整 engine。训练速度/一致性权衡，M4 裁决。
3. **[待定-3] 投影作用域**：全时隙投影 vs 失败侧投影（δ-松弛）。M5 主实验前裁决。
4. **[待定-4] margin_cert 取值**：默认 0；并入 ζ 目标后视 cert 违约率上调。M4 裁决。

## 8. 明确不做（引用 banlist）

Lagrangian/PID 对偶微调、梯度操纵（CRPO/零空间投影）、任何**奖励/损失项**携带可行性
压力（那是命题 T 明确否定的塑形）——可行性只存在于**输出域结构**与 **cert 护栏**，二选一
之外的行为都算违规。

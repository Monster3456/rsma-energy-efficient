## 2. D2：τ 集中度投影原型（零重训）

### 2.1 算法（与形状探针同族，方向封锁）

```
p_logits_raw = Worker(s)                      # 冠军既有动作，冻结
l0 = clip(p_logits_raw, ±3)；l_mean = mean(l0)
tau* = RootFind( f(tau) = zeta_hat(s, l_mean + tau·(l0-l_mean)) >= zeta_gate(s) )
        bisection，τ ∈ [0, 1.2]，5–7 步
p_logits_final = clip(l_mean + tau*·(l0 - l_mean), ±3)
```

- **方向封锁**：τ 只朝**集中**方向推进（上限 1.2，探针示 τ≳1.2 后 clip 地板冻结动作，无意义）；
  禁止均匀化方向（τ<0）。
- **作用域**：仅当 `f(1.2) ≤ zeta_gate(s)` 时**不做根查找**，直接给"本状态无可用集中度证书"警告并保持
  原动作（失败侧不伤害已学行为；全投影作为对照组——两种模式都出数）。
- `zeta_hat`：**fast surrogate**（diff_engine 截断版或单步教师近似）——**完整 engine 作为
  逐点验证口径**（cert），surrogate 只作根查找内循环。
- 逐点性：多个 SNR 点各自有 gate → 根查找对**最紧点**（记录最紧点身份，预期 0/10 dB）执行。

### 2.2 证书（训练与验证分离）

- $S_{\rm cert}$：7 点 × N_state（≥32）× N_slot 的状态采样（复用探针 warmup 协议）；
- 指标：**实证违约率** = #{(s): 任一落在 gate 之下}/#，每点余量分布（min/med/q95）；
- **C1 门 ≤1%**；违约超限 → 记录最紧点与失败模式的几何画像（clip 地板 还是 批量抖动）。

## 3. D3：逐点压力向量观测（廉价臂）

### 3.1 接口

- **来源复用**：`src/training/main.py` 的 HM 状态已维护 7 维逐点 EMA 短差
  （`shortfall = max(_HM_TARGETS − ema, 0)`，第 131 行）；

### 3.2 对照与判据

- 对照：armA 多种子已成（0.9437±0.0044）——与 D3 单种子（手册上须同种子 45 或另起）**配对报告**；

- **D3 判据（ii）**：交付差 **≥ 0.003** 且有处理效应（否则记负，D3 终结，D1 只带 D2 经验前进）。

## 4. Stage-1 关门判据（Q7 预注册）

| 条件 | 阈值 | 动作 |
|---|---|---|
| (i) D2 lift（7×50 官方） | ≥ +0.002 且 cert ≤1% | 进入 D2 通道 |
| (ii) D3 配对照交付差 | ≥ 0.003 | 进入 D3 通道 |
| (i)+(ii) 任一失败 | — | 记负 → 只带成功通道经验写 Stage-2 spec |
| 双失败 | — | D1 降级为理论收尾（命题 T + 探针证据），不再重训 |

阈值取 σ_seed≈0.005 的半噪声带：既容许 D1 上路，也拦无效臂。

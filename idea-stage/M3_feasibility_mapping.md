## 1. 目标与方法定位

**目标**：构造动作头映射 $\phi_\theta$，使输出**结构性落在联合可行域内**：

$$a = \phi_\theta(s,\ z),\qquad \mathrm{range}(\phi_\theta) \subseteq \mathcal{F} = \textstyle\bigcap_s \mathcal{F}_s,$$

其中 $z$ 为低维无约束的"可行域坐标"，$\mathcal{F}_s=\{a: \zeta(s,a)\ge\zeta_{\rm SDMA}(s)\}$（交付门；
队列门在冠军操作点不紧，见三种子官方评估）。

**一句话定位**：这是**唯一默许的突破路径**（命题 T 的推论），也是 DiffOpt 教师上界 0.9574
下 0.6% 摊销缺口（0.9519 → 0.9574）的攻坚方向——冠军和一个"由构造保证 7/7"的策略之间，
差距不在奖励刻度，在输出域是否受约束。

**与被证伪/禁用的区别（换头不换梯度）**：

| 方案 | 错在哪 | M3 的不同 |
|---|---|---|
| 逐桶参数 `group_alpha` | 每点一组参数，H3 已证仍败 | **一个**参数化覆盖 $\cap_s\mathcal{F}_s$，非逐点条件化 |
| Delivery Safety Layer | 训练期无关/表达力不足（约束栈判定无效） | 约束进**头结构**，非动作后纠错 |
| 零空间梯度投影（banlist） | 改**梯度方向**，输出域不变 | 改**输出域**，梯度天然受限 |

## 3. 映射 $\phi_\theta$ 的两条赛道（探针裁决后二选一）

### 赛道 A：解析（份额集中度方向，存活碎片）——探针已修正方向

探针结果（2026-10-29，n_states=4，逐状态曲线 `logs/m3_feasibility_shape.json`）**否定
"总功率阈值"版**：

- **0 dB**：$\zeta$ 随 logit 展宽 $\tau$ 从 0.681（均匀 24 W）**升**到 0.852（冠军 14.4 W）——
  功率越高交付越低，可行方向是**份额集中**而非总功率；
- **15 / 30 dB**：交付对功率平坦或反向（$\rho\approx-0.7\sim-0.9$ 或 $\approx0$），冠军余量
  $+0.05\sim+0.23$ 大且对总功率不敏感；
- 所有点 $\tau\gtrsim1.2$ 后 logit 到 clip 下限饱和，动作冻结——可达策略类有**输出域上限**。

故 $\mathcal{F}$ 不可由 $p_{\rm tot}$ 竖切。可证的解析碎片仅剩**方向性**：

$$\zeta(\tau)\ \text{对固定份额沿集中度 } \tau \text{ 向门推进（0 dB 实测），至 logit 下限饱和}.$$

**结论**：单变量解析映射**降级为方向先验**，不独立成定理；主体走**赛道 B**（学习），
但该方向先验可写进结构——份额上显式加入"集中度坐标 $\tau$"，与状态条件化学习耦合。

### 赛道 B：学习（可微引擎把可行域从结果空间拉回动作空间）——主体路线

探针三证据支持学习路：可行方向是**份额形状**（集中度）、单变量证不通、logit 输出域有上限。
用**可微引擎**（float64 与不可变实现 atol=1e-9，本仓库独有资产）训练"交付逆映射"，作用对象是
**份额 logits 的形状**（含集中度坐标），不是总功率：

$$\phi_\theta: (s,\zeta^*)\mapsto l,\qquad \mathcal{L}_{\rm inv} = \sum_s \text{ReLU}\big(\zeta_{\rm SDMA}(s)-\hat\zeta_s\big)^2 + \lambda\,|l-l_{\rm ref}|^2,$$

其中 $\hat\zeta_s=\hat\zeta(s,\phi_\theta(s,\zeta^*))$ 经 diff_engine 前向。训练后**逐点验证**：
采样状态集 $S_{\rm cert}$ 上检验 $\hat\zeta_s\ge\zeta_{\rm SDMA}(s)$，给出**实证违约率**
作为 $\mathrm{range}\subseteq\mathcal{F}$ 的数值证书。

**优点**：表达力强，不依赖阈值假设；把 $\zeta$ 通道由"软目标"升级为"硬证书"。
**风险**：黑箱映射叙事弱；需 certification 与训练分离防过拟合。缓解：方向先验（§赛道 A）
作初始化/正则，减少黑箱自由度。

## 4. 分叉裁决（探针已执行，2026-10-29 n_states=4）

| 探针事实 | 裁决 |
|---|---|
| 0 dB 交付随集中度升、随总功率降（功率→高交付→低） | **否决"功率阈值"解析版** |
| 15–30 dB 交付平坦/反向，冠军余量大（+0.05~+0.23） | 红线不靠缺功率，靠形状 |
| 全部点 $\tau\gtrsim1.2$ logit 饱和冻结 | 输出域有上限 → 不能靠"加裕量" |
| 结论 | **赛道 B 为主体**；集中度方向作先验进结构；$\zeta$ 作验证坐标 |

**诚实限制（探针口径）**：探针 ζ 是**单时隙代理**（D = min(Rτ,Q)，队列帽在低 SNR 处收窄），
且 split 固定 0.5（非 Meta 实际下发值）——**绝对余量与官方 7×50 不可比**（官方在 0 dB 为
+0.029），本探针结论**只站方向与结构**，绝对门评估一律以官方评估为准。

> 0 dB 确认为最紧点（官方三种子 0.880±0.005，最近；冠军单状态可到门线附近）——与
> 几何探针"0 dB 可行集 15%、在动作分布尾部"互相印证。
